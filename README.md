# 法扣案件公文套版工具

保全法扣作業專用的公文套版工具。選擇案件情境、填寫資料，即可產出公文內文、解約金明細表，並列印套印信封。

線上網址：https://mstuiospace.github.io/csv_tools/

## 資料處理方式

- 純前端靜態網頁，無後端伺服器、無資料庫
- 所有計算在瀏覽器本機完成，不對外傳送任何資料
- 不引用任何外部資源（含網路字型），零對外連線
- 案件資料（債務人、保單、金額）不會被儲存，關閉頁面即消失
- 本機僅留存兩項設定：信封版面校正值、寄件人資訊
- 寄件人資訊由使用者自行設定，程式碼不含任何機關資料

## 功能

- **公文內文**：依填寫資料自動組出主旨與說明段落，一鍵複製（貼到 Word 或公文系統會保留標楷體 16pt）
- **對內備註**：依作業日、給付方式與所選說明自動產生，可手動編輯；一旦手改過就不再被自動覆蓋
- **解約金明細表**：自動計算實領金額、金額防呆檢查，可線上預覽與列印
- **信封套印**：比照信封範本的版面，可微調校正位移後直接套印
- **一鍵清空**：清空案件資料回到初始狀態，保留寄件人設定與信封校正值

| 縮小保額（部分給付分配） | 🚧 開發中 |
| 綜合件（解約＋非解約混合） | 🚧 開發中 |
