# 法扣案件公文套版工具

保全法扣作業專用的公文套版工具。選擇情境、填寫案件資料，就能自動產出公文內文、解約金明細表，並列印套印信封。所有資料僅在瀏覽器本機處理，不上傳伺服器。

線上網址：https://mstuiospace.github.io/csv_tools/

## 功能

- **公文內文**：依填寫資料自動組出主旨與說明段落，可複製純文字或匯出 Word 檔
- **解約金明細表**：自動計算實領金額，可線上預覽、列印
- **信封套印**：比照公司信封實體範本的版面（收件人姓名／地址／郵遞區號／寄件人資訊），可微調校正位移，直接套印在公司信封上

### 最近完成

- 信封套印版面比照公司信封實體範本重做：直書三區塊（郵遞區號／地址、收件人姓名、寄件人資訊＋公文字號），移除自繪郵票框與格線，改為可選顯示的測試參考框；新增版面校正功能（尺寸、各區塊位移可調整，設定會記住）；預覽與列印共用同一份版面，避免兩邊長相不一致；修正直書中數字／英數字的排版方式
- 解約金明細表格式調整：表頭改為純黑字兩行顯示、欄寬重新分配、保單號碼強制換行避免溢出到隔壁欄位、列印邊界改為 1 公分
